# Slingshot Probe

A small browser physics game: drag back, release, and use planets' gravity wells to bend your
probe into the target ring. Five missions, including a moving moon. Fewer launches is better.

**Play:** https://lelekb.github.io/slingshot-probe/

Single `index.html`, no build step, no dependencies (Google Fonts only). Works with mouse and touch.
Progress and best scores are saved in your browser.

Run locally: open `index.html` in a browser.

Ideas for new missions welcome in Issues. MIT License.
